# Express.js Middleware Practice

A beginner-friendly Express.js project for learning and practicing middleware concepts.

## Topics Covered

- Custom Middleware
- Application-Level Middleware
- Router-Level Middleware
- Authentication
- Authorization
- Validation
- Express Built-in Middleware

## Technologies

- Node.js
- Express.js

## Run Project

```bash
npm install
node server.js
```

Server runs on:

```text
http://localhost:3000
```
